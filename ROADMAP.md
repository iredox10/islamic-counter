# Islamic Counter PWA - Feature Roadmap

## Essential Enhancements

### Streak Tracking
- Gamification motivates daily use - show consecutive days of dhikr
- Display current streak, longest streak
- Visual flame/calendar indicator
- Notification when streak is at risk

### Morning/Evening Adhkar Presets
- Pre-built collections (Al-Mathurat, post-Salah adhkar)
- Users can load complete adhkar sets with one tap
- Categorized by time of day (morning, evening, post-prayer)
- Progress tracking for each collection

### Hijri Calendar Integration
- Show Islamic dates alongside Gregorian
- Highlight special days (Laylatul Qadr, Eid, Ramadan, etc.)
- Special adhkar recommendations for significant dates
- Optional: Remind about voluntary fasts (Mondays, Thursdays, White Days)

### Widgets (iOS/Android)
- Home screen widget for quick counting without opening app
- Display today's count and active goal
- Tap to increment directly from widget
- Deep link to full app

### Dark/Light Theme Toggle
- Toggle between dark (current) and light theme
- Auto mode based on system preference
- Preserve user's theme choice

## Engagement Features

### Achievements/Badges
- "First 1000" - Complete 1000 total counts
- "7-day streak" - Consistent daily use
- "Completed 10 goals" - Finish 10 goals
- "Early bird" - Count at Fajr time
- "Night owl" - Count after Isha
- "Century club" - 100 counts in one session
- Visual badge collection page

### Daily Reminders
- Push notification at user-set times
- Preset options: Fajr, after each Salah, before sleep
- Custom time scheduling
- Reminder content: motivational quotes, hadith

### Progress Sharing
- Share goal completion as an image/card
- Beautiful Islamic-styled share cards
- Include count, date, and dua
- Export as image for social media

### Quran/Dua References
- Show benefits/virtues of each dhikr
- Hadith references for rewards
- "Whoever says SubhanAllah 100 times..."
- Link to full dua text when applicable

---

## Quality of Life

### Auto-reset Session
- Option to reset counter at midnight automatically
- Configurable in settings
- Preserves total stats while starting fresh daily

### Multi-counter Mode
- Track multiple dhikr types in one session
- SubhanAllah 33x, Alhamdulillah 33x, Allahu Akbar 33x
- Quick switch between counters
- Combined session summary

### Custom Vibration Patterns
- Different haptic feedback for milestones
- Vibrate at every 33, 100, 1000
- Customizable patterns
- Optional: Sound effects for milestones

### Cloud Backup
- Google Drive/iCloud backup for data safety
- Automatic sync option
- Restore from any device
- Encrypted backup

### Large Count Entry
- Hold button to increment faster
- Long-press to enter number manually
- Swipe gestures for quick increments
- Accessibility: voice input

---

## Technical Improvements

### Offline Indicators
- Visual cue when app is working offline vs online
- Show "Offline" banner when no connection
- Queue sync when back online
- PWA install prompt improvements

### Data Sync Conflict Resolution
- Handle cases where imported data conflicts with existing
- Merge strategy options
- Backup before merge
- Undo capability

---

## Priority Order

1. **Streak Tracking** - High engagement, low complexity
2. **Daily Reminders** - Core feature for habit building
3. **Dark/Light Theme Toggle** - User preference, low complexity
4. **Hijri Calendar** - Adds Islamic context
5. **Achievements/Badges** - Gamification layer
6. **Morning/Evening Adhkar Presets** - Content enhancement
7. **Widgets** - Platform-specific, higher complexity
